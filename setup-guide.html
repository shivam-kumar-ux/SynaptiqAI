SYNAPTIQ ARCHITECTURE GUIDE

Privacy-First, Local-First, BYO-AI Learning Operating System
01
LOCAL-FIRST DATABASE
IndexedDB Storage & PBKDF2 Password Security
  1. All student plans, study history, notes, knowledge graph, and focus statistics live locally on your device in IndexedDB (SynaptiqDB).
  2. Local user accounts use Web Crypto API (PBKDF2 SHA-256 salted password hashing). No remote Firebase dependencies are required.
02
BRING YOUR OWN AI PROVIDER
User Provider Manager & Priority Fallback
  1. Go to Settings -> AI Provider Manager.
  2. Add your own API key for Google Gemini, Groq, OpenRouter, OpenAI, or Anthropic.
  3. SynaptiqAI calls your configured provider directly from your browser. No developer server key proxy is used.
03
ENCRYPTED GOOGLE DRIVE BACKUP
Optional Multi-Device Sync
  1. Connect Google Drive in Settings using minimal scope (drive.appdata).
  2. Your data is encrypted locally using AES-GCM 256-bit encryption before upload.
  3. Sync, restore, and resolve conflicts across multiple devices smoothly.
